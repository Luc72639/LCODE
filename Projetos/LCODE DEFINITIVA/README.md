# LCODE — Site Institucional 2.0

Site institucional da LCODE, feito em HTML, CSS e JavaScript puro.

## Estrutura
- `index.html` — estrutura e conteúdo
- `css/style.css` — identidade visual, responsividade e modo claro/escuro
- `js/script.js` — interações, animações, modal de tecnologias, partículas e contadores
- `assets/images/` — imagens reais dos projetos e fundador

## Deploy estático
Não há etapa de build. O diretório publicado é a raiz deste projeto.
